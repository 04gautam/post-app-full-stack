# Features
User Authentication

### 1. Register new accounts

### 2. Login with existing accounts

### 3. Logout functionality

### 4. Protected routes for authenticated users

### 5. Post Management

### 6. Create new posts

### 7. View all posts

### 8. Like/unlike posts

### 9. View post details

### 10. User Interaction

### 11. Like functionality for posts

### 12. Visual feedback for liked posts

### 13. User-specific post views

Technologies Used
Frontend
React.js

Redux (for state management)

Axios (for API calls)

React Router (for navigation)

CSS/SCSS (for styling)

Backend
Node.js

Express.js

MongoDB (with Mongoose ODM)

JSON Web Tokens (JWT for authentication)

Bcrypt (for password hashing)

Installation
Prerequisites
Node.js (v14 or higher)

npm or yarn

MongoDB Atlas account or local MongoDB installation
